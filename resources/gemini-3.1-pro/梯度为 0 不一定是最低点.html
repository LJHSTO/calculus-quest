梯度为 0 不一定是最低点

本节聚焦：驻点与鞍点

学习目标：能识别三种驻点形状；能知道梯度为 0 只是候选；能解释鞍点为什么不是最值。

直觉解释：梯度为 0 的点叫“驻点”，它可能是局部最小、局部最大或鞍点。仅凭梯度为 0 无法确定它是最低点，还需要结合曲面形状和二阶信息来判断。

概念卡片

• 驻点：梯度（所有方向偏导数）均为 0 的点。
• 局部最小值：周围一圈的值都比它大，像碗底。
• 局部最大值：周围一圈的值都比它小，像山顶。
• 鞍点：一个方向看是谷底，另一个方向看是山顶，它不是最值点。

红色圆点代表观测中心；紫色虚线为水平十字切线，表示梯度为 0。
