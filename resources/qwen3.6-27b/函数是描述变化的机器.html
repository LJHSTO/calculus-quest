函数是描述变化的机器

本节聚焦：函数与输入输出
🎯 学习目标：能说出输入、输出和函数规则；能从图像判断函数在上升还是下降；能理解微积分研究"变化"。

💡 直觉理解

函数就像一台机器——你给它一个输入，它就按照一条固定的规则，给你一个输出。

微积分研究的是输出如何随着输入改变。

🌡️ 温度随时间变化：输入是"时间"，输出是"温度"。函数规则由天气决定。
🚗 路程随时间变化：输入是"时间"，输出是"走过的路程"。
📚 成绩随练习量变化：输入是"练习次数"，输出是"考试成绩"。

⚙️ 输入 → 规则 → 输出

📥 输入 x
x = 1.00
通过右侧滑块改变输入
🔄 函数规则
f(x) = x²
把 x 代入规则计算
📤 输出 f(x)
f(1) = 1.00
这就是函数的输出值
0.20

📊 变化率观察

Δx（增量）
0.20
Δy = f(x+Δx) - f(x)
0.41
差商 Δy/Δx（平均变化率）
2.05
当 Δx → 0 时，差商趋近于导数

🤔 思考题

在 f(x) = x² 的图像上，哪里变化更快？
1.00

📇 概念卡：函数 = 变化的描述器

• 输入（自变量 x）：你给机器的原料

• 规则（函数 f）：机器内部的加工方式

• 输出（因变量 y = f(x)）：机器生产的产品

• 变化率（差商 Δy/Δx）：输出变化快慢的度量——微积分的核心！
