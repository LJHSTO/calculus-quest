亲手算出一个梯度

本节聚焦：梯度计算
🎯 学习目标：你能对二元函数求梯度，代入具体点得到梯度向量，并解释每个分量的几何含义。
💡 直觉解释：想象你站在一个山坡上的某一点。如果你只沿 东西方向（x 轴）走，坡度是多少？这就是对 x 的偏导数。如果你只沿 南北方向（y 轴）走，坡度又是多少？这就是对 y 的偏导数。把这两个方向的坡度按顺序排成一个向量 (∂f/∂x, ∂f/∂y)，就得到了梯度——它指向函数值上升最快的方向，长度表示上升的快慢。

📝 动手计算梯度

已知函数 f(x, y) = x² + 3xy + 2y²，请逐步求出它的梯度。

∂f/∂x = ∂/∂x (x² + 3xy + 2y²) = ？
对 x² 求导得 2x；对 3xy 求导（y 是常数）得 3y；对 2y² 求导（不含 x）得 0。所以 ∂f/∂x = 2x + 3y。
∂f/∂y = ∂/∂y (x² + 3xy + 2y²) = ？
对 x² 求导（不含 y）得 0；对 3xy 求导（x 是常数）得 3x；对 2y² 求导得 4y。所以 ∂f/∂y = 3x + 4y。
∇f(x, y) = ( ∂f/∂x, ∂f/∂y )

📖 概念卡片：梯度是什么？

梯度是一个向量，由函数对每个变量的偏导数按顺序排列组成。对于二元函数 f(x, y)：

∇f = (∂f/∂x, ∂f/∂y)

梯度的方向是函数值上升最快的方向。
梯度的长度表示在该方向上升的速率。
梯度的每个分量表示沿对应坐标轴方向的变化率。
