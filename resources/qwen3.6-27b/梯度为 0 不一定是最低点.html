梯度为 0 不一定是最低点

本节聚焦：驻点与鞍点
学习目标：通过切换三种曲面并观察梯度下降路径，你能识别碗形（最小值）、山顶（最大值）和鞍面（鞍点）的驻点特征，并理解梯度为 0 只是候选，还需结合曲面形状判断。
直觉解释：梯度为 0 的点叫做驻点。驻点不一定是最低点——它可能是局部最小（碗底）、局部最大（山顶），也可能是鞍点（一个方向上坡、另一个方向下坡）。就像站在马鞍上，前后方向和左右方向的感受完全不同。要判断驻点类型，需要观察曲面形状或借助二阶信息（曲率）。
📌 概念卡片：三种驻点
碗形（最小值）：所有方向都是上坡，梯度为 0 时在谷底。
山顶（最大值）：所有方向都是下坡，梯度为 0 时在峰顶。
鞍面（鞍点）：一个方向上坡、另一个方向下坡，梯度为 0 但不是最值。
💡 关键洞察
梯度下降在碗底附近收敛到最小值；在山顶会逃离；在鞍点附近可能卡住，因为两个方向梯度都趋近于 0，但它既不是最小也不是最大。这就是为什么 "梯度为 0 ≠ 最低点"。
