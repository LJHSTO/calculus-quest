用数表理解趋近

数表给出观察线索，距离关系才给出邻近范围内的保证

数表：x 从两侧靠近 1，规则是 f(x) = (x²−1)/(x−1)

x → 1⁻（左侧）1x → 1⁺（右侧）
输入 x0.90.990.999取不到1.0011.011.1
输出 f(x)1.91.991.999无定义2.0012.012.1
两侧的输出都越来越靠近 2；x = 1 本身不在定义域内，只考察 0 < |x − 1| 的输入。

x ≠ 1 时 x²−1x−1 = x + 1，所以 |f(x) − 2| = |(x + 1) − 2| = |x − 1|

要输出误差 |f(x) − 2| < 0.01，只需输入满足 0 < |x − 1| < 0.01

对照 g(x) = 2 + 3(x − 1)：|g(x) − 2| = 3|x − 1|，同样的误差要求就要 0 < |x − 1| < 0.01/3（这个界约等于 0.0033；取更小的窗口，例如 0.003，也同样足够）

先想一想

数表里两侧都靠近 2，就能说明输出一定靠近 2 吗？要把输出误差压到 0.01 以下，输入要靠近到什么程度？

点“查看推理”，按 1 → 2 → 3 逐步展开；每一步会在左侧数表或推导框上点亮对应部分。
1数表只记录有限个点：0.9 得 1.9、0.99 得 1.99，1.1 得 2.1、1.01 得 2.01，两侧都在靠近 2——这是观察到的线索。
2线索要靠距离来说明：x≠1 时式子等于 x+1，于是输出与 2 的距离正好等于输入与 1 的距离，误差和输入同尺度。
3所以取 0<|x−1|<0.01 就能保证误差小于 0.01；换成 2+3(x−1)，距离放大 3 倍，同样要求下输入要被压到 0<|x−1|<0.01/3 以内。
数表给观察线索；距离关系才能在邻近范围内作出保证。
