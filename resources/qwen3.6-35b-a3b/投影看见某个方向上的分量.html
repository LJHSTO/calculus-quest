投影看见某个方向上的分量

本节聚焦：向量投影 · 数学 · 主动学习

🎯 学习目标

掌握向量投影的几何意义：投影是"沿目标方向看见的部分"，夹角越小投影越大，垂直时投影为 0。

💡 直觉解释

想象一束光沿着垂直于某个方向照射过来，向量在这个方向上的投影就像它的"影子长度"。方向导数可以用"梯度在某方向上的投影"来理解。当你改变目标方向时，影子会变长或变短——这就是投影的本质。

🔦 影子的类比

把向量想象成一根斜插在地面上的杆子。阳光从正上方照射，杆子在水平地面上的"影子"就是它在水平方向上的投影。

  • 杆子越接近垂直地面，影子越短
  • 杆子越接近水平，影子越长
  • 如果杆子完全水平，影子就是它自己
  • 如果杆子完全垂直，影子缩成一个点（长度为 0）

📐 关键概念

  • 蓝色向量 x：要被投影的向量
  • 绿色向量 b：目标方向（基向量）
  • 橙色线段：投影向量（在 b 上的分量）
  • 紫色虚线：从 x 到投影的垂线（正交条件）

💡 拖动蓝色或绿色向量的端点，观察投影如何变化！

步骤 1：设定正交条件：向量差 (x - λb) 与基向量 b 的点积为 0。

步骤 2：展开点积公式：⟨x, b⟩ - λ⟨b, b⟩ = 0。

步骤 3：解出 λ = ⟨x, b⟩ / ⟨b, b⟩（即点积除以模长平方）。

结论：投影向量 = λb = (⟨x, b⟩ / ⟨b, b⟩) · b

📦 核心概念卡

投影描述了向量在指定方向上的"影子长度"。公式如下：

投影向量 = (⟨x, b⟩ / ||b||²) · b

其中 λ = ⟨x, b⟩ / ||b||² 是投影系数，表示目标方向上需要多少倍的基向量 b 来合成投影。

构建投影矩阵：P = (b·bᵀ) / ||b||²，用于将任意向量投影到子空间。

⚡ 即时反馈

拖动左侧面板中的滑块或拖动 Canvas 中的向量端点，观察投影的变化。试试让两个向量垂直——你会发现投影长度变为 0！
