# 函数与极限实验章节

本分支是独立、可运行的测试版本，仅包含“函数与极限”一个章节，不包含积分、求导、多元函数或其他扩展课程。分支不继承原仓库的提交历史，原项目分支保持不变。

## 包含内容

- 函数、坐标与图像读法，极限与连续，共两个模块、六个知识点。
- 24 份互动课件，以及配套讲解、音频、图片和共享渲染资源。
- 12 题前测、12 题后测、30 道支架后验证题、18 题延迟保持测。
- 新选择题使用 A–D 四个知识选项，以及独立的“我不会”；保留本章节旧版题目以解释历史记录。
- 登录、学习记录、知识助教、主动支持及管理后台。
- 已包含资源压缩、共享字体和 3D 模块、首页合包及重复请求合并优化。

## 本地运行

使用 Node.js 24。先运行 `npm ci` 安装锁定依赖，再运行 `npm start`。

默认打开 `http://127.0.0.1:8765/`。`server.js` 支持通过命令行参数指定其他端口，例如 `node server.js 8766`。

按 `.env.example` 配置运行环境。默认模型为 mock，不会调用付费模型；真实助教和简答题模型评分需要服务端另行配置。测试配置不是正式研究批准或模型质量验收。

生产部署需要设置仓库外的绝对 `DB_PATH`、私有分组盐、管理凭据及新的实验编号。不要复用已经冻结的其他实验协议。子路径部署可设置 `BASE_PATH=/calculus_quest`。

## 验证与构建

```text
npm test
npm run kg:build
npm run runtime:build
```

修改首页脚本或样式后，必须重新运行 `npm run runtime:build`。修改课程路线后，重新生成知识图谱。构建工具使用本仓库依赖，不需要额外的 OpenMAIC 项目目录。

`ops/test-deployed-learning-browser.js` 可验证实际学习流程，需要本机 Chrome 或 Edge，并显式设置 `LEARNING_BASE_URL` 与 `LEARNING_ALLOW_TEST_ACCOUNT=1`。测试生成的账号不可纳入学生样本。
